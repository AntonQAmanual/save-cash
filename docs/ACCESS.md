# Авторизация устройств — требуемая серверная часть

Статус RC: не реализована и не развёрнута. GitHub Pages не может исполнить серверную проверку. Локальные финансовые данные находятся только в профиле браузера; ссылка на публичный код сама по себе не раскрывает их. Это не замена управлению доступом владельцем.

Для завершения требуется HTTPS backend и выбранный способ первоначальной идентификации владельца Anton Koval. Владелец входит через passkey; сервер хранит публичные ключи, роли и разрешённые устройства. Только владелец выдаёт одноразовое приглашение: криптографически случайный токен, в базе только его хеш, срок 2 часа, однократное атомарное погашение. Новое устройство регистрирует отдельную пару ключей; токен привязывается к зарегистрированному устройству. Сессия — защищённая HttpOnly/Secure/SameSite cookie, короткий срок и серверный отзыв. Приглашённый пользователь не может выдавать приглашения. Владелец видит и отзывает устройства. Сервер проверяет разрешения каждого защищённого запроса, лимитирует перебор и пишет журнал без секретов.

Нужны тесты истечения/повторного погашения приглашения, привязки устройства, конкурирующего погашения, отзыва, CSRF, прав владельца и потери устройства. Авторизация сервера не может отозвать уже экспортированные или ранее сохранённые локальные данные. Публичный JavaScript также нельзя надёжно закрыть клиентской проверкой. Обещать невозможность передачи доступа между людьми технически некорректно; можно ограничивать выдачу новых сессий и устройств.
