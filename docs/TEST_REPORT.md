# Save Cash 3.0.0-rc.1 — проверка 16.10.2026

Статус: **локальный кандидат выпуска; не опубликован и не принят как завершённый релиз**.

## Автоматические проверки

`npm test`: 51 тест, 51 успешно, 0 ошибок. Включены:

- Контроль 1050 − 450 = 600; доли 400/650; 1500 + 200 − 400 = 1300; общая нагрузка 1900; 77 + 668 = 745.
- Компоненты выписки/связанные покупки/уроки без двойного списания; банковский снимок по дате; Hot Wheels 95 вне следующего периода; окончание рассрочки; разовый кредит; источники оплаты Cibus.
- Миграция прежней математики в образование внутри перевода алиментов; подтверждённые исключения долей; компенсация без фиктивного прихода и без автоматического переноса.
- Точные, спорные и отличающиеся датами совпадения; одинаковые суммы разных магазинов; две похожие покупки; конфликт повторного банковского ID; частичная выписка; комиссии отдельные/включённые; изменение данных между подтверждениями; откат и повторное подтверждение.
- Парсер ивритских товаров/скидок/НДС, 180 строк, неоднозначные итоги, неуверенные поля; CSV с ивритскими заголовками и кавычками; реальный SheetJS читает созданный XLSX; реальный PDF.js извлекает текст синтетического PDF. PDF-тест не проверяет отрисовку скана: Node получает заглушку DOMMatrix для текстового пути.
- IndexedDB 2 → 4; сохранение прежней записи; SHA-256 и дедупликация оригинала; ZIP восстанавливает данные и байты вложения в чистой IndexedDB; повреждённый архив отклоняется без изменения базы.
- DOM приложения с выполнением обработчиков: запуск, 7 вкладок, «Все блоки»/назад, баланс через карандаш/журнал без покупки, независимые покрытия зарплаты на 3/4 касании, настройки с правами Anton Koval, открытие только одной спорной карточки, второй этап подтверждения.

`npm run build`: статическая PWA собирается, синтаксис основных модулей и manifest проверяются. Service worker имеет версию по хешу содержимого и полный список локальных OCR/PDF-ресурсов. Это не проверка установки или офлайн-поведения настоящего браузера.

Отдельный запуск **реального Tesseract.js** с локальными heb+eng на синтетическом изображении распознал магазин на иврите, английские товары, дату и итог; оценка уверенности движка 94%. Это только воспроизводимая проверка запуска, не оценка качества реальных финансовых документов. Тестовые банковские операции в приложении не создаются.

Восстановленный личный исходный JSON проверен отдельно, вне репозитория: после миграции сохранены количества покупок, абонплат, рассрочек и истории. Исходный JSON не изменён.
