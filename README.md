# 💰 Save Cash — Бюджет до ЗП

Мобильная PWA: бюджет, Cibus, обязательства, подписки, рассрочки, планы, журнал покупок и постатейная сверка.

© 2026 Anton Koval. Все права защищены. Для личного использования.

Данные хранятся в IndexedDB на устройстве. Публичный код содержит пустой начальный бюджет. Личные суммы загружаются пользователем из его JSON-копии и не отправляются на GitHub или сервер. Экспорт, импорт, перенос старого localStorage на том же origin, резервные снимки и отмена сброса доступны в настройках.

Установка: открыть опубликованный GitHub Pages URL в Chrome Android → меню ⋮ → «Установить приложение» / «Добавить на главный экран». До начала работы загрузить личный JSON или заполнить пустой бюджет.

credit учитывается по дате банковского списания. Компоненты общей выписки и связанные покупки исключаются из повторного списания. Неподтверждённые суммы остаются оценками. Фото чеков можно прикрепить; OCR не подключён. Дневные графики не выдумываются при отсутствии исходных операций.

## Версия 2.2

Счета за иврит и математику содержат отдельные платежи преподавателю с датами списания. Математика — личный расход. Для иврита личная доля округляется вверх до сотни с разницей минимум 100 ₪; доля второго родителя равна остатку. Для небольших счетов личная доля ограничена полной суммой. Компенсация уменьшает алименты однократно по указанной дате, без отдельного прихода денег. Старые ручные суммы сохраняются до создания счёта.

Отметка «В выписке» исключает отдельный расход, уже покрытый общей суммой credit. «Учитывать» управляет строкой рассрочки и не меняет банковскую выписку. Связанный чек за уроки не дублирует платёж счёта.

Импорт `save-cash-lesson-update` добавляет или обновляет только счета с совпадающими ID, сохраняя баланс, покупки и остальные данные. Перед обновлением сохраняется резервный снимок. Повторный импорт не создаёт дубликатов.

Калькулятор и проверка покупок объединены: несколько слагаемых и расчётов, компактная цифровая панель, автоматический итог и влияние на запас. Сценарии сохраняются на устройстве и не добавляются в журнал.

## Версия 2.3

Главная показывает сводку бюджета под семью компактными вкладками: покупки, платежи, ребёнок, Cibus, планы, расчёты и все блоки. Связанные разделы сгруппированы во вкладках. Режим «Все блоки» открывает все существующие разделы вертикально, скрывает вкладки и оставляет кнопку возврата на главную. Переключение представления не изменяет финансовые данные и сохраняет черновик формы покупки.
