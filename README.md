# Save Cash — Бюджет до ЗП

Личное приложение Anton Koval. Версия **3.0.0-rc.1, 16.10.2026** — кандидат выпуска, не подтверждённый Android-релиз.

## Сборка и проверка

Node.js 24: `npm ci`, `node scripts/vendor.mjs`, `node scripts/verify-runtime.mjs`, `npm test`, `npm run build`. Статические файлы для публикации находятся в `.build/dist`. GitHub Pages может также обслуживать корень: `sw.js` генерируется сборкой. Личные данные, чеки и резервные копии никогда не добавляются в репозиторий. Первый запуск пустой.

Самостоятельные модули: `model.js` (учёт), `reconciliation.js` (сверка), `documents.js` (OCR/импорт), `storage.js` (IndexedDB), `backup.js` (ZIP), `validation.js`, `app.js` (существующий интерфейс). Сохранены семь вкладок, все прежние разделы и обе карточки цели экономии.

## Учёт

Одна покупка/чек — одно списание. Детализация покрытой выписки отдельно не вычитается. Датированный банковский остаток исключает уже отражённые списания. Выписка применяется только после двух подтверждений. Неоднозначные совпадения и конвертация без банковской суммы требуют проверки; одинаковой суммы недостаточно для объединения. Компенсация уменьшает алименты и не создаёт банковского прихода.

Доля мамы за иврит: `max(0, floor(total / 2 / 100) * 100 - 100)`. Исключение возможно только с явным подтверждением. Старое ручное значение сохраняется при миграции до ввода настоящего счёта и помечается как прежнее. Зарплата автоматически не меняется. Кредитный платёж — разовый. Рассрочки заканчиваются по своему графику.

«В сумме credit» означает, что строка уже покрыта общей выпиской: она остаётся в истории, но не добавляется к списанию. «Учитывать» включает/отключает прогноз отдельной строки, не меняя сумму банка. Не используйте эти отметки вместо сверки выписки.

## OCR и документы

Tesseract.js с локальными моделями Hebrew + English. Файлы не отправляются внешнему OCR-сервису. Оригинал, исходный результат и исправления сохраняются раздельно. Плохие/неоднозначные поля требуют проверки. Распознавание не гарантирует бухгалтерскую точность. Первый запуск требует загрузки движка и моделей; service worker кэширует их для дальнейшей автономной работы. HEIC зависит от декодера устройства; при ошибке требуется JPEG/PNG.

CSV и XLSX читаются как таблицы; PDF — текст, а сканы и изображения — OCR. Неизвестная банковская разметка может потребовать ручной правки строк в предварительном просмотре. Все строки OCR банка требуют проверки. Повторный файл определяется по SHA-256; конфликт одного банковского ID остаётся спорным. Подтверждённые комиссии могут связываться вручную; предполагаемые комиссии не создаются.

## Данные и резервные копии

IndexedDB версия 4 сохраняет прежние хранилища. ZIP содержит JSON, оригинальные документы и SHA-256 каждого файла. Восстановление проверяет целостность и применяет данные транзакцией. JSON отдельно не содержит вложений. Архив больше 512 MiB в распакованном виде или отдельный файл больше 100 MiB отклоняется для защиты памяти; для больших архивов требуется отдельный путь восстановления. Экспортируйте полную ZIP-копию перед сменой устройства. Локальные данные не синхронизируются автоматически между устройствами.

## Доступ и ограничения публикации

GitHub Pages раздаёт общедоступный статический код. Оно **не обеспечивает** авторизацию новых устройств, двухчасовые коды владельца, запрет передачи доступа или отзыв сессий. Эти функции в RC **не реализованы**. В клиенте нет фиктивного встроенного пароля. Требуемая серверная схема описана в `docs/ACCESS.md`. Нельзя объявлять личный защищённый сервис завершённым до реализации и развёртывания backend.

Удалённая резервная ветка и публикация блокируются ответом интеграции GitHub **403 Resource not accessible by integration**. Текущая опубликованная версия не обновлена этим кандидатом. Установка на физический Samsung, перезапуск телефона, обновление установленной PWA и качество на настоящих чеках не проверены. Подробности — `docs/TEST_REPORT.md`.

## Публикация RC1

GitHub Actions получает зависимости и OCR/PDF-ресурсы официальных поставщиков, проверяет их по `runtime-integrity.json`, выполняет тесты и публикует только `.build/dist`. Бинарные зависимости не требуется хранить в дереве исходников GitHub. Если поставщик изменит файл, проверка целостности остановит публикацию вместо незаметной замены движка. Исходный архив RC1 сохранён отдельно.
